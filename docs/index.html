🚀 各平台客户端运行与控制指南

🪟 Windows 玩家：下载 COGame-Client.exe 后直接双击即可秒开游戏，无需手动执行任何终端命令！

🍎 macOS 玩家：下载 COGame-macOS.zip 解压后直接双击 COGame.app（若遇系统安全提示，请右键选择「打开」或直接双击 Start-COGame.command 启动）。

🐧 Linux / 跨平台：下载 COGame-Client.jar，在终端执行：

java -jar COGame-Client.jar

🖱️ 鼠标直觉操作 (v2.6.0 推荐)：

  • 左键点击任意合法目标格：自动执行 BFS 最短避障寻路步进走子；若点击自身所在格，则根据点击象限改变角色朝向。
  • 右键点击格子：根据鼠标相对格心的上下左右象限，直接精准封锁该边并立即交换行动权！
  • 鼠标悬停：实时高亮可达目标格（淡金微光）并在当前格边缘呈现拟锁边方向三角形指示，所见即所得。

⌨️ 经典键盘快捷键：

  • WASD / 方向键：在步数限制范围内步进移动并转向（可反向退回）。
  • 空格键 (SPACE)：沿角色当前朝向前进一步。
  • R 键：顺时针旋转 90 度。
  • L 键：封锁当前朝向的边，封锁成功后立即将行动权交换给对手！
  • P 键：显示/隐藏双方最短连通路径（高亮线）。
  • F11 键：切换沉浸式全屏。
  • + 键 / = 键：重置棋局。

📜 版本演进历史

v2.6.0 (当前最新版)

  • 双国手架构精简重铸：精简流派为「策天 · 盘枢国手」（Voronoi 领地切割、空间拉伸与战术蓄能）与「绝影 · 贴身猎手」（曼哈顿贴身卡位与极限出度封杀），剔除冗余流派；
  • 3~10 档思考深度滑动条：人机对决弹窗新增深色科技风 JSlider（最低 3，默认 5，最高 10），动态反馈推演深度与策略风格，支持从超快棋到深度长算自由调节；
  • 前瞻深算与防反杀 (Anti-Blunder) 机制：引入多步 Beam Minimax 前瞻推演、一击必杀（Forced Cut）终局斩识别与对手反杀走法强力剪枝，彻底告别后手易被破解问题；
  • 键鼠一体化直觉交互：全面支持鼠标左键点击寻路走子/原地调头、鼠标右键象限定向锁边交权，辅以悬停微光与拟锁边三角形实时预览；
  • 对局内分先验证与优化：局内无缝重置并支持分先重开，验证小盘先手必胜假说；
  • 全平台原生安装包同步升级：Windows .exe、macOS .app 束 (zip)、Linux 通用 jar 全面升级至 2.6.0。

v2.5.0

  • 全平台原生独立分发：新增 COGame-Client.exe (Windows) 与 COGame-macOS.zip (macOS 原生 .app 束 + Retina 高清图标)，双端皆支持开箱双击秒开；
  • 终极统一 CLI 竞技场：新增 ./bin/cogame，支持 play、online、bench，统一调度人与人、人与AI、AI与AI；
  • 拟人化三大独立 AI 棋风：推出 莫衡 (控盘大师)、荆刺 (破局猎手)、玄岳 (铁壁守卫)，并支持全景双能量池；
  • 优化侧边栏行动提示排版：去除冗余当前玩家前缀，确保各分辨率下信息完整居中，绝不溢出；
  • 真实大模型连续会话记忆：局内全程使用单会话（session id）记忆推理，终局自动释放注销，新局独立开启全新对话；
  • 开放式 Stdio JSON 协议：任何语言（Python/C++/Rust）编写的外部 Bot 均可 5 行接入打天梯；
  • 全自动棋谱录像：支持 --record replay.json 导出每步毫秒时延、位移与胜负拓扑数据；
  • 自由分先与公平先手仲裁机制：人机对战自由指定玩家执先 (P1) 或 AI 率先出招 (P2)，验证小盘先手必胜假说；联机大厅与建房支持设置分先意愿，若双方均选先手则由服务端 50/50 掷骰公平裁定。
