《端脑》经典博弈演进

COGame - 6×6 隔断棋盘博弈

模拟漫画《端脑》中双方在 6×6 矩阵中盲目移动并互相封锁通路，直到连通性中断决出胜负的策略棋盘游戏。

一键下载客户端 (COGame-Client.jar)
版本: v2.0.0 (全量独立可执行包) | 大小: 约 63 MB | 环境要求: Java 17 或以上
联机对战服务器正在运行中：ws://<本服务器IP>:8088

🎮 支持的三大对战模式

① 单机双人对战

保留原汁原味的原版操作体验，两人同台设备、同一键盘交替行动与封锁，即开即玩。

② 人机挑战模式

内置启发式割裂连通 AI 算法，智能计算封锁哪条边能最大程度切断你的路径并扩大自身领地。

③ 网络联机对战 (C/S)

客户端通过 WebSocket 连接本服务器，输入相同房间号即可秒配对战，支持双方动作毫秒级同步！

🚀 客户端运行方式

下载 COGame-Client.jar 到本地电脑后，双击即可运行（或在终端执行）：

java -jar COGame-Client.jar

也可通过命令行参数快速进入指定模式：

  • 单机模式：java -jar COGame-Client.jar --local
  • 人机模式：java -jar COGame-Client.jar --ai
  • 联机对战：java -jar COGame-Client.jar --online ws://<服务器IP>:8088 1001 玩家名

⌨️ 游戏操作指南

  • WASD / 方向键：移动当前行动角色并改变朝向。
  • 空格键 (SPACE)：沿角色当前朝向前进一步。
  • R 键：角色顺时针旋转 90 度。
  • L 键：封锁当前朝向的边（关键操作），若封锁成功则切换至对手回合！
  • P 键：开启/隐藏双方当前的最短连通路径（蓝色高亮）。
  • + 键：重置棋局重新开始。
