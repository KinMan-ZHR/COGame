COGame - 《端脑》隔断棋盘博弈 (macOS 专属版本)
=================================================

【运行方法】
方法 1 (推荐)：
  直接双击 COGame.app 启动游戏。
  若提示「无法打开，因为来自未知的开发者」：
  请在 COGame.app 上右键（或按住 Control 键点按）-> 选择「打开」即可。

方法 2 (备用免限制)：
  直接双击「Start-COGame.command」脚本即可秒开。

【运行环境要求】
  需安装 Java 17 或更高版本。
  如未安装，启动时会自动弹出下载指引，或通过 Homebrew 安装：
  brew install openjdk@17
